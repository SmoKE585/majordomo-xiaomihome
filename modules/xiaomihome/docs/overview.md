# Xiaomi Home — обзор

Модуль принимает события шлюза Xiaomi/Aqara по локальному протоколу:
multicast-группа **224.0.0.50**, UDP-порт **9898**. Шлюз сам рассылает
сообщения о суб-устройствах, а MajorDoMo раскладывает значения по свойствам и
вызывает привязки объектов.

Облако Xiaomi для работы не нужно. Приложение Mi Home или Aqara Home
используется только для настройки шлюза и получения ключа.

## Разделы

| Раздел | Адрес | Назначение |
| --- | --- | --- |
| Устройства | `/panel/xiaomihome.html` | список, поиск, фильтр по типу, статус, живое обновление |
| Карточка | `/panel/xiaomihome/<id>.html` | обзор, свойства, справка |
| Свойства | `/panel/xiaomihome/<id>/data.html` | значения и привязки |
| Привязка | `/panel/xiaomihome/<id>/bind-<cmd>.html` | объект, свойство, метод |
| Настройки | `/panel/xiaomihome/0/settings.html` | bind IP, округление, порог доступности, журналы |
| Инструкция | `/panel/xiaomihome/0/help.html` | как включить локальный протокол и где взять ключ |

Старые ссылки `?action=xiaomihome&view_mode=...` открываются:
`search_xidevices`, `edit_xidevices`, `update_settings`.

## Что происходит с данными

- шлюз присылает `heartbeat`, `report`, `read_ack` и другие сообщения;
- модуль создаёт запись в `xidevices`, строки метрик — в `xicommands`;
- новые значения пишутся в привязанные свойства объектов MajorDoMo;
- изменение свойства объекта ставит команду в `xiqueue`, цикл отправляет её
  шлюзу с подписью ключа.

## Ограничения

- Поддерживаются устройства, которые шлюз отдаёт по локальному протоколу.
  Камеры, BLE и облачные сценарии — вне модуля.
- Для команд записи нужен 16-символьный ключ шлюза; без него работает только
  чтение.
- UDP 9898 может слушать только один процесс. Порт занят — цикл пишет ошибку.
- На сервере с несколькими сетями multicast может приходить не с той сети:
  укажите IP интерфейса в настройках.
